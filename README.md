# Workit Landing Page - Frontend Technical Test

Solusi untuk *technical test* pembuatan *landing page* Workit (Frontend Mentor challenge).
Dibuat dengan bbrp persen AI slicing tools, murni *setup* untuk *pixel-perfect UI*.

## 🛠 Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Bun (Package Manager)

## 🚀 Cara Menjalankan Lokal

1. Clone repo ini
2. Install dependencies:
   ```bash
   bun install
   ```
